### Agent 与 skill

- **[skills](https://github.com/max1874/skills)** — 在真实任务里打磨过的 agent skill。`deep-read` 让 agent 真的把长材料读完，并证明读完了。
- **[open-computer-use](https://github.com/max1874/open-computer-use)** — macOS 上的 computer-use agent，动作空间带索引，不靠截图，也不靠坐标。
- **[demo-agent](https://github.com/max1874/demo-agent)** — 用 TypeScript 从零写的 agent，不用框架。

### iOS 应用 · App Store

- **[Swipe Photos - 滑动整理相册](https://apps.apple.com/cn/app/id6791112005)** — 一张一张滑，该留的归进相簿，该删的删掉。
- **[小豆记账](https://apps.apple.com/cn/app/id6762084545)** — 截图识别账单记账：支付截图直接变成一笔流水，快捷指令一键记账。

### macOS 应用

- **[Lumo](https://github.com/max1874/lumo-releases)** — 在 macOS 任何地方选中文字即可翻译。
- **[TypeSwitch](https://github.com/max1874/type-switch)** — 打出你手头的字，得到你想要的语言。
- **[Rotap](https://github.com/max1874/Rotap)** — 录下 Mac 正在播放的声音，可混入麦克风，不用虚拟声卡。
- **[open-keyboard-clean-tool](https://github.com/max1874/open-keyboard-clean-tool)** — 清洁 MacBook 时锁住键盘，别的什么都不做。

### 自托管

- **[Ferry](https://github.com/max1874/ferry)** — 你的所有设备，一条时间线，跑在自己的网络里。剪贴板和文件互传，单个 Go 服务。
- **[funnysurge](https://github.com/max1874/funnysurge)** — 我自己维护的 Surge 与 Clash / Mihomo 分流规则。
