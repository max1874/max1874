### Agents & skills

- **[skills](https://github.com/max1874/skills)** — Agent skills hardened on real work. `deep-read` makes an agent actually read a long source to the end, and prove it.
- **[open-computer-use](https://github.com/max1874/open-computer-use)** — A macOS computer-use agent with an indexed action space. No screenshots, no coordinates.
- **[demo-agent](https://github.com/max1874/demo-agent)** — An agent written from scratch in TypeScript. No framework.

### macOS apps

- **[Lumo](https://github.com/max1874/lumo-releases)** — Translate what you just selected, anywhere on macOS.
- **[TypeSwitch](https://github.com/max1874/type-switch)** — Type the words you have, get the language you meant.
- **[Rotap](https://github.com/max1874/Rotap)** — Record what your Mac is playing, optionally mixed with your mic. No virtual driver.
- **[open-keyboard-clean-tool](https://github.com/max1874/open-keyboard-clean-tool)** — Lock the keyboard while you clean your MacBook. Nothing else.

- **[funnysurge](https://github.com/max1874/funnysurge)** — Personal rules, deliberate routes. Surge and Clash / Mihomo rule sets.
